# GrowAI智能体 · Windows 使用说明

## 第一次打开

1. 从作品首页下载 `GrowAI-Windows-x64.zip`，右键选择「全部解压」。把解压目录放在当前用户可以写入的位置，例如「文档」。
2. 打开解压后的 `GrowAI` 文件夹，双击 `Start-GrowAI.cmd`。压缩包自带运行环境，启动时会打开默认浏览器。请保持启动窗口运行。
3. 若浏览器没有自动打开，在地址栏输入 `http://localhost:8081/coach`。首页会显示当前阶段；若提示选择阶段，点「创建或选择阶段」。
4. 先试本地功能：打开「更多选项」→「查看本周状态」。也可用底部的「计划」查看日历。这两项都可以在配置模型之前体验。

## 体验 AI 排程

1. 关闭正在运行的启动窗口。双击同一文件夹中的 `Configure-AI.cmd`，粘贴自己的 DeepSeek API Key 并回车。密钥输入时屏幕不显示字符。再次运行 `Start-GrowAI.cmd`。
2. 在「智能体」输入“明天下午练听力30分钟”，点击「发送」。若当前阶段已结束，先在「我的」中选择覆盖今天和明天的阶段。
3. 核对建议卡上的任务、日期和起止时间。点击「确认并添加」或「确认执行排程」，再点「查看当天日历」核对落点。对时间不满意时可以取消建议。
4. 「更多选项」中还可以调整已有安排或生成本周复盘。模型请求需要联网，费用由所配置的供应商账户承担。

使用其他兼容模型时，把 `backend/.env.example` 复制为 `backend/.env`，填入相互匹配的 `LLM_BASE_URL`、`LLM_MODEL` 和 `LLM_API_KEY`，保存后重启。已有配置请直接编辑。请将密钥留在自己的电脑上。

## 关闭和排查

- **结束使用**　在启动窗口按 Ctrl+C，或直接关闭该窗口。下次使用时双击同一个 `Start-GrowAI.cmd`。
- **提示端口被占用**　检查是否已有 GrowAI 启动窗口，先关闭旧窗口再重开。若其他程序占用 8081，请关闭占用该端口的程序，再启动 GrowAI。
- **提示缺少运行文件**　重新执行「全部解压」，确认 `runtime`、`web`、`backend` 和启动文件位于同一目录。
- **网页打开但模型请求失败**　先确认「查看本周状态」能读取，再核对模型配置、账户余额和网络，重启后重试。
- **找不到之前的数据**　使用原来的浏览器、用户配置和访问地址。Web 数据保存在该站点的浏览器存储中，清除站点数据前，可在「我的」导出业务备份。会话与排程回执的范围以备份面板提示为准。
- **手机访问**　打开同目录的《手机使用.md》，按私有 HTTPS 步骤连接。电脑端服务保持运行。
