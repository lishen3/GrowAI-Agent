# 在手机上使用 GrowAI

Windows 包把网页和 AI 后端放在同一个地址。手机浏览器使用自己设备的 IndexedDB。电脑与手机分别保存记录；第一次使用时，先在“我的”选择阶段，或从已导出的 JSON 备份恢复。

## iPhone 或 Android 通过 HTTPS 使用

1. 在 Windows 上完整解压作品压缩包。双击 `Configure-AI.cmd` 配置自己的模型密钥。如果使用其他兼容供应商，可根据 `backend/.env.example` 在解压目录创建 `backend/.env`，填写 `LLM_BASE_URL`、`LLM_MODEL` 和 `LLM_API_KEY`。
2. 在电脑和手机安装 Tailscale，登录同一私有网络。双击解压目录中的 `Start-Mobile.cmd`，设置本次手机登录密码，并填写每日模型预算及单次费用上界，单位均为人民币分。保持此窗口运行。
3. 在电脑另开 PowerShell，运行 `tailscale serve 8081`。按首次启动提示启用私有 HTTPS 服务，使用终端给出的完整 HTTPS 地址。在手机浏览器打开此地址加 `/coach`，用户名为 `growai`，密码为第 2 步设置的密码。
4. 进入智能体，直接输入“下周三练听力30分钟”并发送。需要查看本周状态时，打开“更多选项”。看到时间建议后点确认，打开日历核验。电脑和两端的 Tailscale 保持在线时可调用模型。
5. iPhone 在 Safari 分享菜单选择“添加到主屏幕”，启用“作为网页 App 打开”；Android 在 Chrome 菜单选择安装应用或添加到主屏幕。首次在线打开并完成缓存后，可以离线查看本地页面。AI 生成需要网络。

单次费用上界应按所用模型在供应商处可能收取的最高单次费用填写，包含输入、输出及推理计费。系统在每次向供应商发送请求前按此上界预扣，包括失败和兼容格式重试。设置过低会低估费用。建议同时设置供应商账户侧的硬限额。预算用完后仍可查看本地记录。默认同时允许两个模型请求；可在解压目录的 `backend/.env` 设置 `GROWAI_MAX_CONCURRENT`。日预算按北京时间零点更新，重启保留已预扣记录。手机访问密码与供应商密钥分开。

常见情况：手机页面能打开但提示模型未配置时，检查电脑端的 `backend/.env` 后重启；若访问地址打不开，检查电脑是否休眠以及两端是否连接同一私有网络。普通局域网 HTTP 地址缺少排程确认和 PWA 安装需要的安全上下文。

## Android 通过 USB 使用

电脑安装 Android Platform Tools，手机打开 USB 调试并授权此电脑。双击 `Start-GrowAI.cmd`，在电脑运行：

```powershell
adb devices
adb reverse tcp:8081 tcp:8081
```

看到设备状态为 `device` 后，在手机 Chrome 打开 `http://localhost:8081/coach`。此包只需转发一个端口；网页和 API 均由该端口提供。拔线后连接中断。localhost 适合连接测试；安装离线 PWA 使用上面的 HTTPS 入口。
